# cv-agentic

Personal CV site: **React + TypeScript + Vite + ESLint + CSS Modules**,
responsive, with a **light/dark** theme and **en/es** languages, built by
OpenCode agents with spec-driven development.

It is a **single project** at the root: the **design kit** (rules, tokens,
foundations, specs and data contract) lives together with the app's code, which
Phase 1 creates (`src/`, `index.html`, `package.json`). "The kit" in this
documentation refers to those design documents, not to a package.

## Structure

```
cv-agentic/
├─ README.md          presentation of the repo, in English (#120)
├─ AGENTS.md          conventions for the agents (OpenCode reads it from the root)
├─ docs/              documentation: constitution, STATUS (status), full README, DESIGN,
│                     BACKLOG, diagnostics, memory, agent-system.md (format and permissions),
│                     qa-report.md (F5), tokens/ (breakpoints, contrast) and images/
├─ tokens/            tokens.css (code: the app imports it)
├─ foundations/       typography · layout · motion · theming · i18n
├─ specs/             one spec per piece (foundation, primitives, controls, layout, content, pages, hooks) + motion/proposal.md
├─ data/              data contract of the CV (@data alias) + example content
├─ .opencode/         agents/ (the 5 agents), skills/sdd/, commands/ (/sdd-*)
├─ opencode.json      OpenCode config (Chrome DevTools MCP, only for the reviewer)
└─ src/ · public/ · index.html · package.json · vite.config.ts   ← the app
```

## How the app uses the kit

```ts
// src/main.tsx — tokens: only once, by relative path
import "../tokens/tokens.css";
```

```ts
// in any file of src/ — types with the @data alias
import type { CvData, Locale } from "@data/cv.types.generated";
```

- The alias `@data/*` → `data/*` is configured in `tsconfig.json` (`paths`) and in
  `vite.config.ts` (`resolve.alias`); Phase 1 does it.
- **The tokens are not copied to `src/`.** A single source of truth.

## Reading order for an agent

1. `docs/constitution.md` (non-negotiable rules)
2. `docs/DESIGN.md` (hard design rules)
3. `tokens/tokens.css` + `docs/tokens/contrast.md` + `docs/tokens/breakpoints.md`
4. The `foundations/*.md` relevant to its task
5. The spec of the assigned component in `specs/…`
6. `data/cv.schema.json` if it touches data (and `foundations/i18n.md` → Content)

## Scope

- **Panels**: About (introduction, services, testimonials) and Resume
  (Experience, Projects, Education, Skills as chips).
- **Structure**: Sidebar (identity, networks, contacts, Download CV), NavTabs
  (tablist in a corner tab, always visible), ControlsBar (theme + language).
- **Out**: see `docs/DESIGN.md` → "Out of scope".

`engines.node`: `"^22.12.0 || >=24"`).
