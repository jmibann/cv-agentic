## Pure functions and algorithm

None. The page only reads collections of the `cv` in the given order (RF-5) and
maps texts. The derived ids (`resume-education-title`, items `${prefix}-…`)
are generated by the child pieces; here only the prefixes `"edu"`/`"exp"` are set.

## Interface

`ResumePageProps { className?: string }` → joined to `.page` (G-B, the same pattern as
AboutPage). Data `useCv()`; `const { t, locale } = useLocale()` — `locale` is
the **provider's active language**, not `cv.locale` (specification clarified in
the F4 Clarification, P7).

## Decisions

- **`timelineIdPrefix` fixed by the page** (`"edu"`, `"exp"`): they are the contract
  that ResumeSection explicitly delegates (its decision 14); discarded
  alternative — internal derivation (forbidden by that spec).
- **Forwarding of `presentLabel` as an RF of its own with a mocked test** (P6): the
  rendering of "Present" belongs to Timeline (an implemented piece, tested there);
  this page only guarantees passing the label; the test does not depend on the
  kit's fixture keeping an `end: null`.
- **`vi.mock` with `importOriginal` to empty/inject** (P1, shared with
  AboutPage): discarded alternative — opening a content prop in
  `LocaleProvider` (F1 files closed).
- **The "both collections empty" case** absorbs the state of RF-2 in the extended
  test 5 (mock); the absence of `.columns` is verified by inspection of the
  generated markup (there is no hook for testing a hashed class).
- **No `role="list"`** on skills (it comes from SkillList): quirk unified in F5.

## Test strategy

The same pattern as AboutPage: `region` by name (`t.resume.education`,
`t.resume.experience`, `t.resume.skills`), `listitem` per entry/skill,
`getAllByRole heading level 1` length 1, `es` test with locale `es`, closing
`expectNoA11yViolations`. Content mock for `end: null` and empty ones. The
layout clauses (grid ≥ md, `grid-column: 1 / -1`, no-BFC) by inspection
of the CSS + QA F5 (the spec declares it); "without sorting" by code inspection.

Coverage: T1→RF-1,RF-2(columns),RF-5(incl. test 7 es) · T2→RF-7,RF-2(empty ones) ·
T3→RF-4 · T4→RF-3,RF-6 (inspection) + `className` join + a11y closing case.
